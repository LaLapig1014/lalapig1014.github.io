# lalapig1014.github.io

個人介紹網站，使用 React + TypeScript + Vite 建置，部署於 GitHub Pages。

**網址：** https://lalapig1014.github.io/

---

## 功能

- 開場動畫（進度條 + 終端打字效果）
- Banner 影片背景
- 粒子漂浮背景特效
- 背景音樂播放控制
- 分頁式內容區塊（簡介 / 工作經歷 / 作品集）
- 作品集輪播展示

## 技術

- React 18 + TypeScript
- Vite
- CSS Modules

## 本地開發

```bash
npm install
npm run dev
```

## 建置與部署

```bash
npm run build
# 將 dist/ 內容複製至此 repo 並 push
```
